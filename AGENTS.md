# Agent instructions

Use `.agents/skills/ste-pipeline-communication/SKILL.md` for Knowledge Bits pipeline engineering communication, including implementation plans, debugging reports, code reviews, architecture decisions, incident analysis, test reports, task handoffs, and pipeline status summaries.

Prefer precise, direct engineering prose. Separate facts from hypotheses. State the next action when one exists.

Do not apply this communication standard to learner-facing Nuglet editorial content, stories, audio scripts, hooks, or marketing copy.
